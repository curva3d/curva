# Status

Curva is built by two streams of work, each in its own sessions. Each stream writes only its own
status page, so two sessions never edit the same file:

- **Features** (commands, geometry, documents, and the interface outside the viewport):
  [`status/features.md`](status/features.md). It also holds the project's history up to
  15 November 2026.
- **Display** (the viewport: drawing, display modes, speed on large scenes):
  [`status/display.md`](status/display.md).

Read both before starting work; write only yours. Who owns what is in `AGENTS.md`.
