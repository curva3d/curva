**Curva 0.4.0, preview.** A fixed Curva top bar and one panel system for everything, an AI Assistant in
its own panel, updates with one click, a gumball that extrudes and stretches, and 36 more of Rhino's
commands. Still early: expect rough edges, and keep copies of anything you care about.

## Download

| System | File |
|---|---|
| Windows (64-bit) | `curva-v0.4.0-windows-x64-setup.exe`: an installer for your user only, with no administrator rights |
| Linux (64-bit) | `curva-v0.4.0-linux-x86_64.AppImage`: make it executable (`chmod +x`) and run it |
| macOS (Apple silicon) | `curva-v0.4.0-macos-arm64.dmg`: open it and drag Curva to Applications |

The builds are not signed with a developer certificate yet:
- **Windows:** SmartScreen may warn about an unknown app. Choose "More info", then "Run anyway".
- **macOS:** the first time, open System Settings → Privacy & Security and choose "Open Anyway".

From this version on, Curva checks for updates when it opens and offers them in the command bar.

## New since 0.3.0

**The interface**
- The top bar is **Curva**: always there (focus mode hides it), with the file's name, **File** and
  **Settings**, and the specializations as a dial: Freeform, Architecture, Publisher, Analysis. Only
  Freeform has commands yet.
- **Commands**, **Display** (the view's display mode) and **Settings** are panels like the others.
- Every panel has a **cross** to close it (it asks first, and Settings → Interface brings it back), a
  **V** that points to the edge it hides to, and tabs you can **drag to reorder**.
- **Settings** has tabs: General (theme, glass or solid, units, grid, updates), Interface (every panel
  with a switch, and Reset interface), AI Assistant, and About.
- The same type and colours on every panel; glass a quarter more see-through; Curva's name and
  version at the bottom right; the window opens filling the screen.
- Every command has an **icon**, and the Commands panel gains **Analyze** and **Select** tabs.

**AI Assistant**
- Chat with an assistant that works on your model, from its panel: a **ChatGPT** account (through
  OpenAI's Codex), a **local model** through LM Studio, or an **OpenAI or Claude API key**.
- Instructions to connect an external assistant (Claude Desktop, Claude Code) through MCP.

**Modelling**
- New: Sphere, Cylinder, Cone, TruncatedCone, Torus, Tube, Ellipsoid, Paraboloid, Polygon, Slot,
  Helix, Spiral, Parabola, Points, Lines, Plane, SrfPt, ExtrudeSrf, ArrayLinear, Align, BooleanSplit,
  DupEdge, ChangeDegree, Angle, Radius, EvaluatePt, What, AreaCentroid, VolumeCentroid, SelLine,
  SelPolyline, SelCircle, SelArc, SelClosedCrv, SelOpenCrv, HideSwap, and SaveAs.
- The gumball's circle extrudes curves and surfaces and stretches solids (Shift stretches anything,
  Shift+Ctrl scales evenly); its scale square is gone. Every gumball action snaps.
- Width × depth shows beside the pointer while drawing rectangles and boxes, and a typed size shows
  there too.
- Ctrl+C, Ctrl+X, Ctrl+V and Ctrl+A work on objects.

**Fixed**
- After clicking in a viewport, typing reaches the command line again, so options like Circle's
  `2Point` can be typed; they can also be clicked.
- Escape ends a command but keeps what it already placed (Copy's copies), and clears the selection when
  nothing is running.
- Ghosted views snap like Wireframe.
- Previews of heights no longer jump while the view turns.
- Curves and edges are drawn twice as thick.
- FilletEdge and ChamferEdge previews are no longer hidden by the original solid.
- Resizing a panel no longer selects things behind it, and a stray orange line on the top panel is
  gone.

## Known gaps

- No Rhino (.3dm) import or export yet.
- Many of Rhino's surface tools (Sweep2, NetworkSrf, EdgeSrf, Patch, BlendSrf, surface trimming) wait
  on the geometry engine; `docs/commands/rhino-parity.md` lists every command and its state.
- In shaded views, curves hidden behind a solid's faces (such as a curve under the solid extruded from
  it) cannot be snapped to; switch to Ghosted or Wireframe to reach them.
- On Windows a console window opens beside Curva.
