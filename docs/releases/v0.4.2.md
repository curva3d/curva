**Curva 0.4.2, preview.** Milestone 2: Rhino `.3dm` files opened and saved, blocks, live booleans,
and every Rhino NURBS command that was waiting on the geometry engine. A new icon too. Still early:
expect rough edges, and keep copies of anything you care about.

## Download

| System | File |
|---|---|
| Windows (64-bit) | `curva-v0.4.2-windows-x64-setup.exe`: an installer for your user only, with no administrator rights |
| Linux (64-bit) | `curva-v0.4.2-linux-x86_64.AppImage`: make it executable (`chmod +x`) and run it |
| macOS (Apple silicon) | `curva-v0.4.2-macos-arm64.dmg`: open it and drag Curva to Applications |

The builds are not signed with a developer certificate yet:
- **Windows:** SmartScreen may warn about an unknown app. Choose "More info", then "Run anyway".
- **macOS:** the first time, open System Settings → Privacy & Security and choose "Open Anyway".

If you have 0.4.1, Curva offers this update in the command bar when it opens.

## New since 0.4.1

**Rhino files (.3dm)**
- **Open** reads Rhino files from Rhino 5 to 8 as a new model, which then saves as a `.curva` file
  beside the `.3dm` (never over it). **Import** adds a `.3dm` (or `.curva`) to the open model, its
  layers merged by name. **Export**, **ExportSelected** and **SaveAs** write Rhino 7 files, which
  Rhino 7 and 8 open. The File tab's Import and Export buttons run them.
- What comes across: units, layers (nested ones as `Parent::Child`), points, lines, polylines, arcs,
  circles, NURBS and poly-curves exactly; surfaces, polysurfaces and solids with their trims; Rhino's
  extrusion objects as solids; names, print widths, user text, groups, hidden and locked objects;
  blocks and their instances; named views and named construction planes.
- Meshes, SubD, point clouds, annotations, hatches and render settings are left out, and the command
  bar says how many of each.
- Curva's own live booleans and History are written as plain geometry.
- Written in Curva's own Rust, from the format openNURBS documents; a damaged file is refused with a
  message, never a crash.

**Blocks**
- Block definitions and instances, nested, embedded in the model or linked to another file (read again
  when that file changes): Block, Insert, BlockManager, ExplodeBlock, BlockEdit, and a Blocks panel.

**Live booleans**
- BooleanUnion, BooleanDifference, BooleanIntersection and BooleanSplit keep their inputs, hidden,
  inside the result, and the result follows when you change them. EditBoolean and BreakBoolean.

**Every Rhino NURBS command**
- With the geometry engine: EdgeSrf, NetworkSrf, Patch, ExtendSrf, Untrim, Section, Contour,
  Intersect, Project, MoveFace, PushPull, Shear, RebuildUV, CurvatureGraph, Cap.
- With Curva's own geometry where the engine cannot yet: ExtractIsocurve, ShrinkTrimmedSrf, BlendSrf,
  MatchSrf, Twist, Bend, Taper, Flow, CageEdit, Pull, InterpCrvOnSrf, OffsetCrvOnSrf, Silhouette,
  UnrollSrf, ExtrudeFace, FilletSrf, ChamferSrf. Each is listed in `docs/kernel/custom-operations.md`
  and checked against the engine before every release.
- Sweep2 uses the engine's new two-rail sweep, certified within 0.001.
- Zebra and DraftAnalysis.

**Organising**
- Count, ChangeLayer, MatchProperties, Linetype, PrintWidth, SetUserText, GetUserText, Purge, Audit,
  LockSwap, UnlockSelected, BringToFront, SendToBack, BringForward, SendBackward, DupFaceBorder,
  TextObject, and NamedCPlane (construction planes saved by name, as NamedView saves views).
- Trim, Lock, Unlock, Group, Ungroup, SelColor and Plan now work like every other command, with their
  options at the prompt.

**The icon**
- The Drafting mark, with its architectural construction, is Curva's icon.

## Known gaps

- Meshes and SubD come after Milestone 4; section hatches and the other drafting tools are
  Milestone 3.
- In shaded views, curves hidden behind a solid's faces cannot be snapped to; switch to Ghosted or
  Wireframe to reach them.
