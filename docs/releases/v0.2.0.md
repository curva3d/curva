**Curva 0.2.0, preview.** Milestone 1 is complete, and the interface is new: floating panels over the
model, a frosted command bar, and a focus mode. Still early: expect rough edges, and keep copies of
anything you care about.

## Download

| System | File |
|---|---|
| Windows (64-bit) | `curva-v0.2.0-windows-x64-setup.exe`: an installer for your user only, with no administrator rights. Adds Curva to the Start menu, and can be removed from Settings → Apps |
| Linux (64-bit) | `curva-v0.2.0-linux-x86_64.AppImage`: make it executable (`chmod +x`) and run it |
| macOS (Apple silicon) | `curva-v0.2.0-macos-arm64.dmg`: open it and drag Curva to Applications |

The builds are not signed with a developer certificate yet:
- **Windows:** SmartScreen may warn about an unknown app. Choose "More info", then "Run anyway".
- **macOS:** the first time, macOS will refuse to open Curva. Open System Settings → Privacy & Security
  and choose "Open Anyway" next to Curva.

## New since 0.1.1

**The interface**
- The viewports fill the window. The panels float over them with rounded corners:
  - command tabs at the top (Curves, Surfaces, Solids, Operations), each with its most used commands
  - Layers and Properties on the right
  - a frosted-glass command bar at the bottom, with the snaps, Ortho, Grid snap and Gumball beside the
    command line, and the agent (MCP) connection on the right
- **Focus mode:** the small arrow at the top centre, or F12, slides the panels to the window's edges.
  Hover a panel's strip to peek, click it to bring that panel back, or start typing to bring the
  command bar out.
- **Your own arrangement:** drag a panel by the grip at its top-left to dock it to any edge, or let it
  float. Floating panels resize from their corner. Right-click a grip for **Reset layout**. Curva
  remembers your arrangement.
- Curva has its icon: the C through three control points.

**Modelling**
- `Curve`, the control-point curve, with `Degree` and `Close`.
- `ScaleNU`: a different scale along each axis, for solids too.
- `SelSrf`, `SelSolid`, and `Volume`.
- The selection filter: `SelFilter` shows Points · Curves · Surfaces · Solids in the bottom bar, so
  clicks and boxes pick only the kinds ticked; `SelFilterToggle` turns it off and on.
- **Ghosted** display, beside Wireframe and Shaded: see-through faces with the edges behind them showing.

**Files and safety**
- **Autosave:** every 5 minutes, if the model changed, Curva keeps a recovery copy. After a crash it
  offers the model back at the next start.
- `.curva` files are now zip packages, about 13 times smaller. Older files still open.
- Saving writes beside the file and then replaces it, so a failed save never leaves a half-written file.

## Known gaps

- No Rhino (.3dm) import or export yet.
- `Cap` is not available: the geometry engine leaves capped solids hollow (reported upstream as
  tangency-labs/solidcore#3266).
- A pipe along a rail with a sharp corner is refused; smooth rails work.
- On Windows a console window opens beside Curva.
