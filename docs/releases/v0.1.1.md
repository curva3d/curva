**Curva 0.1.1, preview.** The same Curva as 0.1.0, now packaged the usual way for each system. It is
early and unpolished: expect missing commands, rough edges and file changes between versions.

## Download

| System | File |
|---|---|
| Windows (64-bit) | `curva-v0.1.1-windows-x64-setup.exe`: an installer. It installs for your user only, with no administrator rights, adds Curva to the Start menu, and can be removed from Settings → Apps |
| Linux (64-bit) | `curva-v0.1.1-linux-x86_64.AppImage`: make it executable (`chmod +x`) and run it |
| macOS (Apple silicon) | `curva-v0.1.1-macos-arm64.dmg`: open it and drag Curva to Applications |

The builds are not signed with a developer certificate yet:
- **Windows:** SmartScreen may warn about an unknown app. Choose "More info", then "Run anyway".
- **macOS:** the first time, macOS will refuse to open Curva. Open System Settings → Privacy & Security
  and choose "Open Anyway" next to Curva's entry.

## What is in it

**The window.** Four viewports (Top, Front, Right, Perspective), wireframe and shaded display, a
command line with autocomplete and aliases as in Rhino, a gumball, layers and properties panels, object
snaps, ortho and grid snap, and custom construction planes (`CPlane`).

**Curves.** Line, Polyline, Circle, Arc, Rectangle, Ellipse and points. Join, Explode, Split, Trim,
Offset, Fillet, Chamfer, FilletCorners, TweenCurves, Rebuild, Divide, CloseCrv, Flip and Dir. Control
points: PointsOn (F10), InsertKnot, RemoveKnot, Smooth. History on Mirror and Offset.

**Transforms.** Move, Copy, Rotate, Rotate3D, Scale, Scale1D, Scale2D, Mirror, Orient, Orient3Pt,
Array, ArrayPolar and ArrayCrv, with live previews.

**Surfaces and solids.** Box, ExtrudeCrv, PlanarSrf, Revolve, Loft, Sweep1, Pipe and OffsetSrf.
BooleanUnion, BooleanDifference and BooleanIntersection. FilletEdge, ChamferEdge and Shell, picking
edges and faces in the viewport.

**Selection, views and measuring.** SelAll, SelCrv, SelPt, SelName, SelLayer, SelDup, SelLast and
others, Hide, Show and Isolate, Zoom and NamedView, Distance, Length, Area, BoundingBox, and volume
and area in the properties panel.

**Files.** Save and Open in Curva's own `.curva` format.

**Agents.** `curva --mcp` lets an AI agent read the scene, run commands and see a picture of a view,
in the open window, behind the Agent access checkbox and with your approval for destructive actions.

## Known gaps

- No Rhino (.3dm) import or export yet, and no autosave.
- `Cap` is not available: the geometry engine leaves capped solids hollow (#67).
- A pipe along a rail with a sharp corner is refused; smooth rails work.
- On Windows a console window opens beside Curva.
- The icon is a placeholder, and on Windows and macOS Curva uses the system's default app icon.
