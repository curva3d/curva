# Decisions

One short note per significant decision, written so the project owner can follow it without a
technical background. Number them in order: `0001-short-name.md`, `0002-...`.

Each note answers: **what was decided, why, what was rejected, and what would make us revisit it.**
A decision is never edited away. If it changes, write a new note that replaces the old one and
mark the old one "Replaced by NNNN".
