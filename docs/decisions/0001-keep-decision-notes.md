# 0001 — Keep a decision note for every significant choice

**Status:** Accepted · 8 November 2026

**Decision:** Every significant choice gets a one-page note in this folder.

**Why:** Agents start each session with no memory of the last. Without written reasons, the same
questions get reopened and good choices get quietly undone. The owner also needs to follow the
reasoning without reading code.

**Rejected:** Keeping decisions in chats or issue comments. They get lost.
