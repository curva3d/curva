# 0038: Everything open ships in 0.4.4

**Status:** Decided by the owner in chat · 19 November 2026. Replaced by 0039 (21 November 2026: 0.4.4 ships what is ready).

**What was decided.** Curva 0.4.4 contains everything that was open on 19 November 2026: the mesh
and SubD work, live plans, the display work, the remaining features, the tidy-up from the
19 November code health review, and the owner's pending decisions. The full numbered list is
`docs/specs/release-0.4.4.md`, and every item is in the GitHub milestone **0.4.4**. It is released
when every item is built and checked in the app, with no fixed date. Three items that wait on other
projects (#67, #381, #349) ship only if those projects are ready in time.

**Why.** The owner wants the next update to carry all of it, as 0.4.3 carried all of Milestone 3
(decision 0023).

**Consequence.** New work that is not on the list goes into the next update unless the owner adds
it, so 0.4.4 can finish.
