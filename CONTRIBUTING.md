# Contributing to Curva

Thank you for helping. Before you start:

1. **Read `AGENTS.md`.** It holds the rules for every contributor, human or AI: where work comes
   from (GitHub Issues labelled `agent-ready`), code rules, tests and how pull requests are merged.
2. **Sign the Contributor Licence Agreement** (`CLA.md`), once. When you open your first pull
   request, a bot asks you to comment with this exact sentence:

   > I have read the Curva CLA and I hereby sign it.

   Pull requests can only be merged once every author has signed. You keep the copyright in your
   work, and your contribution always stays available under Curva's open-source licences. The
   agreement also lets the project offer Curva under other terms, for example in paid editions.
   Why: `docs/decisions/0026-contributor-licence-agreement.md`.
3. **Licences.** The application crates are GPL-3.0-or-later with a plugin exception; the libraries
   are MIT OR Apache-2.0. See the Licence section of `README.md`.
