Every project starts with a curve. Curva is an open-source 3D suite for architects and designers: it models freely, like Rhino, its objects remember how they were made, and its plans, sections and sheets come live from the model, like Revit and Archicad.

These pages cover Curva 0.1.5 and Freeform, the specialization that's out now. They take you from installing Curva to your first model. If you already use Rhino, start with **Coming from Rhino**: most of what you know works the same way.

<Aside type="caution" title="Curva is an early preview">
Things change from one version to the next, and some commands are still missing options. These pages describe the latest release. If something here doesn't match what you see, [tell us on GitHub](https://github.com/curva3d/curva/issues).
</Aside>

## Help and feedback

- **Something doesn't work?** Open an issue on [GitHub](https://github.com/curva3d/curva/issues), with what you did and what you expected.
- **Want to see what's coming?** Each specialization has a page on [curva3d.com](/) that shows what it will do. The full plan is in [`docs/architecture.md`](https://github.com/curva3d/curva/blob/main/docs/architecture.md) on GitHub.
